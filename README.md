# Customer Churn Analysis

Analysis of why customers leave, with insights and an interactive Power BI dashboard to help improve retention.

## Overview

- Cleaned and explored customer data to find churn patterns
- Identified the key factors linked to churn (contract type, tenure, charges, etc.)
- Built a Power BI dashboard with KPIs and filters
- Summarized recommendations to reduce churn

## Repository Structure

```
├── Data/          # Dataset

```
